## Commands for you

1. **Push.** No remote exists yet. Create the GitHub repo, then:
   `git remote add origin <url> && git push -u origin main`
2. **Docker.** Port 9092 is used by your `dtxsim-kafka-1` container, so run ours with `KAFKA_PORT=9094`. **Credential helper:** `~/.docker/config.json` has `"credsStore": "desktop"`, but `docker-credential-desktop` is not on PATH, so `docker compose up` fails on the image pull. Either add it to your shell profile:
   `export PATH="$PATH:/Applications/Docker.app/Contents/Resources/bin"`
   or remove the `credsStore` line. (I put it on PATH for single commands only and did not change your config.)
3. **Rust for the desktop app (M6).** `cargo` is not installed: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`

4. **Hook false positive.** `~/.claude/hooks/block-destructive.py` blocks any Bash command containing the SQL keyword it guards, even as a plain word. It fired twice: on a React file using Tailwind's text-overflow utility class of the same name, and on this very note. Nothing destructive was involved. I did not bypass it: code uses the equivalent classes (`overflow-hidden text-ellipsis whitespace-nowrap`), and files are written with the editor tools. Consider matching only real SQL statements (keyword + `TABLE`). M9 work on the SQL-…TRUNCATED code will keep hitting it.
