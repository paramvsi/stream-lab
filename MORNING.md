## Commands for you

1. **Push.** No remote exists yet. Create the GitHub repo, then:
   `git remote add origin <url> && git push -u origin main`
2. **Docker credential helper.** `~/.docker/config.json` has `"credsStore": "desktop"`, but `docker-credential-desktop` is not on PATH, so `docker compose up` fails on the image pull. Either add it to your shell profile:
   `export PATH="$PATH:/Applications/Docker.app/Contents/Resources/bin"`
   or remove the `credsStore` line. (I put it on PATH for single commands only and did not change your config.)
3. **Rust for the desktop app (M6).** `cargo` is not installed: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
