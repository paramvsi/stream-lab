Motion explains cause and effect: an event moves, then the window fires. Never decoration.

Nothing loops on screen except running streams and loading indicators.

Live numbers change in place; they never slide or bounce.

Simulator speed (1×, 4×, 16×) scales stream motion only, never UI motion.
